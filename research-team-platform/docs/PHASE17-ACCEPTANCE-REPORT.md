## 3. Not done

The full brief is not complete. The data model is still project-membership based; it does not have first-class nested teams, team assignment lifecycle or team-scoped Security Rules. The complete researcher profile and director team-management requirements are not implemented. There is no milestone entity or full project schema for research type, questions, methodology, priority and project deliverables.

The current task workflow has statuses, progress/work notes, comments and in-app notifications, but it does not store immutable versioned submissions and separate review records, structured reviewer-feedback/revision history, task-linked deliverable versions or historical artifact snapshots. The Reports page is a live overview with existing exports, not a configurable date/filter/report builder; the dashboard is not the full requested executive dashboard. There are no scheduled deadline or push notifications.

No staging usability/mobile/RTL test, real email-delivery/auth flow, real signed upload, real Firebase Auth custom-claim integration test, Supabase-to-Firebase dry-run, reconciliation, Rules deployment or hosting cutover has occurred.
